## 🌌 The Vision

We live in a post-text world. Why are you still typing "white pill 500mg" into Google?

**Drug Detect AI** is the interface between **Physical Reality** and **Digital Intelligence**. It uses specific Computer Vision algorithms to decode the molecular identity of any drug from a single photo.

**TL;DR:** It's Shazam for Medicine. And it actually works.

---

## ⚡️ The Capabilities (No Fluff)

| Feature | The Tech | Why it matters |
| :--- | :--- | :--- |
| **Visual Cortex** 👁️ | `Gemini 2.5 Vision` | Decodes crumpled foils, handwriting, and weird fonts. |
| **Semantic Map** 🧠 | `Vector Similarity` | Maps "headache pill" -> "Paracetamol" instantly. |
| **Safety Net** 🛡️ | `Logic Chain Analysis` | Checks if mixing Drug A + Drug B = 💀. |
| **Smart Link** 🔗 | `Dynamic Routing` | Auto-finds the stock on 1mg/Amazon. Tech that saves time. |

## 🛠️ The Stack (Under the Hood)

We kept it lean. No bloat. Just speed.

*   **Intelligence**: **Google Gemini 2.5 Flash Lite** (Low latency, high accuracy).
*   **Backbone**: **Python Flask** (Stateless, serverless-ready).
*   **Visuals**: **CSS3 Glassmorphism** (Custom shaders, no heavyweight frameworks).
*   **Deploy**: **Vercel** (Edge network).

### 🛡️ Zero-Downtime Protocol
We implemented a **Round-Robin Key Rotation** strategy.
*   **The Issue**: Free APIs hit limits (Rate Limiting).
*   **The Fix**: The backend holds a `List[Key]`. If Key 1 fails (429), it **hot-swaps** to Key 2 in <10ms. Seamless.

## 🚀 Deployment (Ship It)

Want your own instance? Ez.

### 1. Clone
```bash
git clone https://github.com/manishpatil55/drug-detect-plus.git
cd drug-detect-plus
```

### 2. Install
```bash
pip install -r requirements.txt
```

### 3. Config (`.env`)
Create a `.env` file. This is your command center.
```ini
# INFINITE UPTIME: Add keys comma-separated.
GEMINI_API_KEY=key_alpha,key_beta,key_gamma

# SPEED:
GEMINI_MODEL=gemini-2.5-flash-lite
```

### 4. Ignite
```bash
python app.py
```
*Live on `http://localhost:5000`*

## 📡 Debugging Protocol

| Signal | Status | Fix |
| :--- | :--- | :--- |
| **429** | Resource Exhausted | Add more keys to `.env`. The system handles the rest. |
| **500** | Internal Error | Bad image format. Try PNG/JPG. |
| **Spinning** | Network Latency | Refresh. Check your wifi. |
